## Legend

- named: The symbol of the function is not a placeholder. The file `config/names.tsv` has an accepted row for the function.
- open: The function is in assembly. The ledger has a row for the function.
- finished: The function is in C. The build is byte-identical. No readability finding is inside the lines of the function.

The tool charges each readability finding to the function that holds the line of the finding. Thus, a join or a split of files does not change a count.

The site [decomp.dev](https://decomp.dev/anzaldoivan/mmx5) is the authority for matched code.
