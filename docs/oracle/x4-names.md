# X4 names for shared X5 code

Generated by `tools/sig/x4adapter.py --doc` from `docs/oracle/x4-names.tsv`; never hand-edited.

Each row is an X5 address with a real name from sozud/mmx4 (AGPL-3.0, pin `34f37a4`). A `gate` or `bytes`
row is an X5 function of 8 words or more whose compiled body equals an mmx4 function under X5's compiler: its
only partner, or partners that all carry one name (`same-name <n>` in the basis), or the one partner the
relocation slots of other aliased functions point at (`slot <n>`). The name is an alias: a search key for the
X5 address, not a symbol.

- tier `gate`: the X5 function is banked in C (proven-at-gate).
- tier `bytes`: the signature is exact and the body is still assembly (consistent-with-bytes).
- tier `slot`: a lead, not a proof. Two or more aliased functions reference this address in the relocation
  slot where their mmx4 twin references that symbol, and none says otherwise. Votes are agree/disagree.
- scope `object`: the mmx4 source is one object's file; identical bytes do not prove the same role, so the
  name stays an alias until a role basis exists. Scope `engine`: everything else.
