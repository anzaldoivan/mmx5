# C0177 — Equal-constant store pair in reversed order: a chained assignment stores the right target first
tags: codegen,store-order,chained-assignment,sh,constant,pair · date: 2026-10-20 · phase/task: 3.3/T9 · origin: W31 FAC00

symptom: two halfword stores of one constant come out in source order. The target stores the higher offset first (`sh 0x26`, then `sh 0x24`).
lever: a chained assignment `p[0x12] = p[0x13] = v;` stores the inner (right) target first.

## Residual

## Lever
