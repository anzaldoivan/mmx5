# C0212 — Constant address held in $s across calls: the body is a sibling helper, inline it (static inline)
tags: codegen,inline,helper,cse,constant-address,scratchpad,callee-saved,call · date: 2026-10-24 · phase/task: 3.3/T22 · origin: W44 slus 8003CEDC

symptom: a constant scratchpad address (`D_1F800024`) is used by repeated calls. Ours holds it in a callee-saved reg across the calls (`li $s0,0x1f800024`). The target re-issues lui/lw before each call and saves no $s.

mechanism: explow.c:444 memory_address forces a CONSTANT_P address into a reg. Then cse shares it across the calls of one body. A volatile view on the 2nd use does not help. The address constant is still shared.

lever: the body is a sibling helper, inlined. Declare it `static inline` with the sibling's body: `func_8002C338(id, D_1F800024 + idx*32, n)`. Call it once per use.
