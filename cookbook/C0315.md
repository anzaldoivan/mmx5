# C0315 — Loop counter steps by 0x01000000 with sra 24: declare the loop index s8 i
tags: codegen,loop,index,s8,sra,sign-extend,counter,m2c · date: 2026-11-06 · phase/task: 3.4/T23 · origin: W88 slus 80016384

symptom: a loop counter steps by `0x01000000` and each test is `sra 24` then `slti`. The m2c seed writes a shifted `s32` counter.

cause: gcc keeps an `s8` loop index in the high byte of a register. Then the increment is `addu 0x01000000` and the sign extend is one `sra 24`.

lever: declare the loop index `s8 i`. Use one `s8 i` for all loops that show the pattern. Discard the seed's shifted counter.
