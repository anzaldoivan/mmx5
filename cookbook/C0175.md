# C0175 — Several fail exits in the wrong block layout: early return-0 guards, one shared return 1
tags: codegen,early-return,guard,block-layout,return,delay-slot · date: 2026-10-20 · phase/task: 3.3/T9 · origin: W31 395E8

symptom: a predicate with several fail exits (`return 0`) and one success has the wrong block layout. Ours puts `return 1` in each arm and one trailing `return 0`.
lever: write guard clauses: `if (a) return 0; if (!b) return 0;`. Each arm ends `if (c) return 0;` then its store, and one shared `return 1` closes the function.
