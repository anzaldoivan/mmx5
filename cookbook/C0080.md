# C0080 — Abs-window test: a condition ternary keeps the negative arm out of line, one store tail
tags: idiom,cse_expr,abs,ternary,cross-jump,branch,bltz,window · date: 2026-10-06 · phase/task: 1.8.2/T15.1 · origin: current/T14 c15

symptom: abs-window test `|a-b| <= lim` guarding one store block: ours `bgez d` with both arms cross-jumped into one shared `slt`/branch; target `bltz d` to an out-of-line negative arm, store block shared once
lever: cond_ternary_abs_window

Write the window test as one condition ternary: `if ((d >= 0) ? (d <= lim) : (b - a <= lim)) { store }`, not `if (d >= 0) { if (d <= lim) store } else if (b - a <= lim) store` nor an if/else-return form.
Nested if / if-else (either arm order): both compares cross-jump into a shared compare tail (`bgez` + one `slt`), store block duplicated or merged differently.
Ternary in the condition: one jump tree with the negative arm out of line (`bltz`), each arm its own compare, a single store tail.
Tell: target branches `bltz d` forward to a recomputed `b - a` (not `negu d`) and has one copy of the guarded stores.
Related: C0079 (abs per arm in stores), C0050 (cross-jump law).
