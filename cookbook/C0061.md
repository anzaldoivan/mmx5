## Mechanism
Pass group `cse_expr`; the front end's pointer_int_sum scales an integer added to a typed pointer by the pointee size (size_exp); a scaffold that already holds a byte offset (`i << 2`) added to an `int *` is scaled again, so ours shifts by 4 (x16) where the target shifts by 2. Cite: `gcc/c-typeck.c:2680 size_exp` (staged tree refs/gcc-2.95.2-psx/). Map: docs/codegen-map/cse_expr.md §E4 (nearest; front-end pointer scaling, not a map pass).

## Lever
cast through a byte pointer: `*(int *)((char *)p + (i << 2))` (char has size 1, the offset is used as written); or drop the scaffold's own scaling and write `p[i]`.
