## Mechanism
The pass group is `cse_expr`. The front end's pointer_int_sum scales an integer added to a typed pointer by the pointee size (size_exp). When a scaffold already holds a byte offset (`i << 2`) and adds it to an `int *`, the front end scales the offset again. So ours shifts by 4 (x16) where the target shifts by 2. Cite: `gcc/c-typeck.c:2680 size_exp` (staged tree refs/gcc-2.95.2-psx/). Map: docs/codegen-map/cse_expr.md §E4 (nearest: front-end pointer scaling, not a map pass).

## Lever
Cast through a byte pointer: `*(int *)((char *)p + (i << 2))`. Because char has size 1, the front end uses the offset as written. Or drop the scaffold's own scaling and write `p[i]`.
