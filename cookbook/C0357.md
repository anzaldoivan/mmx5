# Cross-jump merged an arm: write the arms with opposite branch polarity and gotos

Tell: the residual is a branch pair. The target has `beq F; j T` / `beq F`, and ours has `bne T; j F`.
Or a block of one arm merged into a later identical block (gcc 2.95 jump.c find_cross_jump).
C0080's condition ternary does not move it.

Move: split the shared condition into two arms whose tests have opposite polarity.
End each arm in a `goto` (`// !FAKE:`) to the shared labels:
`if (d >= 0) { if (d > 0x20) goto two; } else { if (oy - dy <= 0x20) goto rnd; goto two; }`.
The arms reach the join in different branch forms, so cross-jump does not merge their slt/beq.
Then reorg inverts the negative arm to the target's form.
Forms with the same polarity in both arms stay put or merge into one shared slt.
