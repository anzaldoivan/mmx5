# C0208 — One-pass loop index tested with beqz: declare it u32, unsigned i < 1 folds to i == 0
tags: codegen,loop,index,unsigned,u32,beqz,blez,compare · date: 2026-10-24 · phase/task: 3.3/T21 · origin: W43 slus 8001F1B0

symptom: a one-pass loop (`for (i = 0; i < 1; i++)`) is not unrolled. The target tests the index with `beqz` after the increment. An s32 index gives `blez` (1 word of diff), and a u8 index adds an `andi` (17 words).

lever: declare the index `u32`. Unsigned `i < 1` folds to `i == 0`, which gives the `beqz`.
