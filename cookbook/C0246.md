# C0246 — Two-way byte dispatch whose first test inverts: a two-case switch, not if/else-if
tags: codegen,switch,if-else,block-layout,beqz,case · date: 2026-10-25 · phase/task: 3.3/T30 · origin: W52 F12B0_ovl05

symptom: a two-way dispatch on a byte written as `if (v == 0) ... else if (v == 2)` inverts the first test. gcc emits `bne` and lays the second arm first.

lever: write the dispatch as a two-case `switch` with a break per case. The compiler lowers it to a `beqz`, `beq`, `j` chain. The case blocks follow case order, with no jump table.

## Instance
W52 F12B0_ovl05 (c25), match at try 2. The if/else-if chain at try 1 was 14 of 25 words off.
Related: C0169 (the converse, where the if/else-if chain matches), C0072 (case order inside a switch).
