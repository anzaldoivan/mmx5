# C0250 — One p+i addu shared across blocks where the target recomputes it: s8 array members in a struct view
tags: codegen,cse,addu,struct,array-member,index,lb,address · date: 2026-10-25 · phase/task: 3.3/T31 · origin: W53 slus 8003FCC0

symptom: two byte tables in one struct are read at `p + i` in separate blocks. The target recomputes the `addu` of p and i in each block. Ours computes it once and shares it.

cause: byte casts like `(p + i)[K]` or `(p + K)[i]` reduce to the same `p + i` sum. CSE then reuses that sum across blocks.

lever: view the object as a struct with s8 array members at the offsets and read `p->unk9B[i]` and `p->unk94[i]`. Each component array ref forms its own address, so the sum is not shared.
