# C0163 — NULL is undefined under include/types.h: write 0 in drafts
tags: harness,draft,types,null,cc1 · date: 2026-10-20 · phase/task: 3.3/T5 · origin: W27 F4C48 FAC04

symptom: cc1 error `NULL` undeclared on a draft compiled through `waves.py try`
lever: write `0` (or `!= 0`) instead of `NULL`

include/types.h defines no `NULL` and drafts include only types.h (and addr.h).
Compare pointers with `0` (`if (child != 0)`). Two W27 drafts lost a try to it (F4C48_ovl29, FAC04_ovl58). Both matched once `0` was written.
Do not add `NULL` to include/ from a draft: include/ is off-limits to draft coders.
