# C0295 — Hoisted base setup before a PRE-inserted lui: assign the base local in the loop body
tags: codegen,loop,hoist,gcse,PRE,lui,preheader,base-pointer,local · date: 2026-11-01 · phase/task: 3.4/T15 · origin: W80 slus 8003432C

symptom: a loop uses a base local of a global and a second global. The target has `lui %hi(D2)` before the hoisted base setup. Ours puts the base setup first and the `lui` after it.

cause: gcse PRE inserts the `lui` of the second global at the end of the preheader. A base local set before the loop is already in the preheader, before that insert. A base local set in the loop body is invariant. Then loop.c hoists it after the PRE insert.

lever: assign the base local inside the loop body, not before the loop. Write `for (i = 0; i < 9; i++) { b = D_8009A0A0; p = (s16*)(b + 0xA8) + i; ... }`.
