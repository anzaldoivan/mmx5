# s16 negation: `x = -x` vs `x *= -1`
- gcc 2.95 psx: `x *= -1` on an s16 field emits `lh` + `negu`, but `x = -x` emits `lhu`. Pick the form whose load matches the target.
- Evidence: one target (1.8.3 T5 c9).

## Extension: an s8 local negated into a byte (W89)
W89 slus func_80044CD0 (c38) is the `s8` analogue. The target negates the sign-extended copy (`move`, then `negu`). `o[0x98] = (s8)t * -1;` with a `u8` local `t` gave the match at try 15. `-(s8)t` negates the raw `lbu` value (43-word diff). An `s8`, `s16` or `s32` local folds the load to `lb`.
