# Reloc rename idiom: instantiate a masked-only dup member from the rep body

- A masked-only dup member (words differ only in %hi/%lo/jal reloc fields) is instantiated from the rep body with
  `#define sym_R sym_M` per differing reloc symbol, when:
  - per reloc slot, type + in-place addend agree (C0039)
  - the map sym_R -> sym_M is a function
  - every sym_M is in the member's own object (`_ovlNN` = its overlay, no suffix = main exe)
  - no renamed sym_R is a struct field, param or local in the body
  - raw words are equal outside reloc fields.
- Only the per-binary whole-binary SHA build catches a wrong rename. Reloc fields are masked in the
  word compare, so a wrong symbol passes it.
- Bisect slus before rockx5: rockx5 links slus, so a slus red shows up in both.
- Tool: `tools/dedup/propagate.py sweep [--dry-run] [--binary <alias>]` (tools/dedup/README.md `### sweep`).
