# C0207 — Compare temp copied in the then-arm: the copy fills the beqz delay slot
tags: codegen,regalloc,delay-slot,temp,copy,compare,then-arm,move · date: 2026-10-24 · phase/task: 3.3/T21 · origin: W43 F3048

symptom: the target fills a `beqz` delay slot with `move a1,v1`, copying the compared counter into the result register. Ours has a nop there, or the counter and result share one register.

lever: compare a separate temp (`s32 t = ((s8*)p)[0x27]; if (t < 0x20)`). Copy it into the result variable as the first statement of the then-arm (`c = t;`).

## Instance
W43 F3048_ovl20 (c4). Reusing one variable for the counter and the result went from 18 to 5 words. A separate compare temp `t` with `c = t;` in the then-arm then matched. Writing `c = t;` before the if was coalesced and changed nothing.

## Byte proof
Rider (T21.c50, `harvest.py rider`, strip = `c = t;` moved before the if). Load-bearing on rockx5 func_800F3048_ovl20 (banked W43).
