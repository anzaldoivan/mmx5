# C0231 — Global base plus a separate addiu, not hi(D+off): write p = D then p += n
tags: codegen,global,address,hi,lui,addiu,pointer,base,fold · date: 2026-10-24 · phase/task: 3.3/T25 · origin: W47 FB404

symptom: the target loads a global array base with `lui`/`addiu D` and then adds the element offset with a separate `addiu +8`. Ours folds `&D[2]` into `%hi(D+8)`/`%lo(D+8)` (diff 18 words).

lever: set the pointer to the base, then advance it in a second statement: `p = D; p += 2;`. gcc keeps the separate `addiu`.
