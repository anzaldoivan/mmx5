# C0266 — Global minus local swaps v0 and v1: read the global into an s32 local in each arm
tags: codegen,global,local,v0-v1,regalloc,per-arm,subtract,if-else · date: 2026-10-31 · phase/task: 3.4/T4 · origin: W69 F3B18_ovl03

symptom: an arm computes `G - e` from a global `G` and a local `e`. The target builds the `%hi/%lo` pair of `G` in v0 and v1 in one order. Ours swaps the two registers.

lever: in each arm, read the global into its own `s32` local first. Write `d1 = G; e1 = ...; ratan2(d1 - e1, ...)`. Then write `d2 = H` and `e2` in the other arm.

Give each arm its own pair of locals. One shared local goes to global allocation and breaks the other arms.
