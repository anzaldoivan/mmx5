# C0218 — Switch over a default store loses its case-0 test: case 0 re-stores the default
tags: codegen,switch,case,default,store,beqz,block-layout · date: 2026-10-24 · phase/task: 3.3/T22 · origin: W44 slus 8004CED0

symptom: a switch overwrites a default pointer store that is set before it. The target keeps a `beqz` test for case 0 that jumps to the join. An empty `case 0: break;` loses that test (26 of 38 words differ).

lever: let case 0 store the default again: `case 0: *(u8**)(a0+0x50) = D_default; break;`. gcc drops the redundant store late, but the case-0 test stays.
