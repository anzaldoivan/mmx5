# C0199 — Table call with the pointer in $5 and $4 untouched: pass the incoming a0
tags: codegen,jalr,call,argument,regalloc,fn-table,a0,passthrough · date: 2026-10-24 · phase/task: 3.3/T18 · origin: W40 F63E4

symptom: a `jalr` through a function table has a `nop` delay slot. The target holds the pointer in `$5`, and `$4` is never written since entry. Ours holds the pointer in `$4`.

cause: the call takes the incoming `a0` unchanged. With no argument, gcc is free to put the pointer in `$4`.

lever: type the table `void (*[])(u8*)` and pass the incoming argument: `tbl[((s8*)a0)[5]](a0)`.

## Instance
W40 F63E4_ovl01: the argless call gave diff 2 words. Passing `a0` matched.
