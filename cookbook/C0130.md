# Absolute addr.h constant to let the lw macro reuse the lui register

Symptom: the target loads `%hi(D_x)` into the register that then receives the value (lui v1, then lw v1). Ours puts the lui in v0.

Lever: read the global as an include/addr.h absolute constant, for example `#define D_801F3004 (*(s32*)0x801F3004)`. Do not use an extern symbol. The assembler's lw macro then reuses the destination register for the lui.

Byte proof: slus func_8001F950, W1 draft `diff 2 of 159` at +0x224 and +0x228. The addr.h constant gives `match`. The harvest rider is load-bearing (2.8 T10).

Use it only when no other C file refers to the symbol. Constants live only in include/addr.h (C0099, C0100).
