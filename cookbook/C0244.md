# C0244 — Byte table at an offset in a global, addu base-first: s8 array member in a struct view
tags: codegen,addu,operand-order,struct,array-member,index,lb,address · date: 2026-10-25 · phase/task: 3.3/T30 · origin: W52 slus 80019DF0

symptom: one `addu` puts the base register first where the target puts the index first. The read is a byte table inside a big global, `D[0x1B8 + idx]`. Every flat or pointer form keeps the swap or folds 0x1B8 into `%hi`.

lever: view the global as a struct with an s8 array member at the offset, `struct { u8 pad[0x1B8]; s8 f1B8[1]; }`, and read `D.f1B8[idx]`. The component array ref keeps 0x1B8 as the `lb` offset and flips the addu operands.
