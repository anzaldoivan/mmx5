# C0161 — Shared switch cases fold to a range test: write each case's body separately
tags: codegen,switch,case,range,cross-jump,duplicate-body · date: 2026-10-20 · phase/task: 3.3/T5 · origin: W27 FC718

symptom: ours folds two switch cases into one `sltiu` range test. The target tests each value.
lever: write the shared cases as separate identical bodies, not stacked labels

## Residual
`case 0: case 1:` sharing one body: gcc 2.95 merges the two labels into one range test. W27 FC718_ovl07 diff 27 of 47.

## Lever
Give each case its own copy of the body (`case 0:` and `case 1:` each with `f(obj, 0x15)` and `break`).
The case tree then tests each value. Cross-jumping merges the identical tails afterwards, as in the target.
Same family as C0151 (range fold of an if-condition) and C0156 (duplicate body, then cross-jump).
