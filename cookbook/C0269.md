# C0269 — Callee-saved register stored but never set: store an uninitialised local
tags: codegen,regalloc,uninit,local,callee-saved,s-reg,store · date: 2026-10-31 · phase/task: 3.4/T5 · origin: W70 FAEC4_ovl07

symptom: the target stores a callee-saved register to a field, for example `s2`. No instruction in the function sets that register. Each variant that stores a constant or a computed value adds an instruction.

lever: declare a local and never assign it. Store that local to the field. Give it the field type, for example `u8 u`. Keep it alive across the calls. gcc then puts it in a callee-saved register and stores the register as it is. Mark the declaration with a comment that says the value is never set.
