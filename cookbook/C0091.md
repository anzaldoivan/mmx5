# PCSX-Redux Lua: pad override, one instance, buffered stdout
- The pad override is `PCSX.SIO0.slots[1].pads[1].setOverride(b)` with a dot call (a colon call gives "Invalid argument"). The button constants are at `PCSX.CONSTS.PAD.BUTTON`.
- Two Redux instances in parallel stall one. Run boots serially.
- Redux stdout is buffered until quit, so a killed run leaves no log lines. End every script with `PCSX.quit`.
- Seen: 1.8.3 T2 (tools/redux/prove_ovl3839.lua, docs/ops/oracles.md).
