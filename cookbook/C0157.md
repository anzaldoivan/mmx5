# Signed zero test of a u8 byte: read it through (s8*) to keep lb

`if ((s8)p[3] != 0)` on a `u8*` compiles to `lbu`: the cast is folded, since the sign does not matter to a zero test. When the target has `lb`, read the byte through a signed pointer: `if (((s8*)p)[3] != 0)`.

Diff without it: 1/24 at +0x34 (rockx5 func_800F51F4_ovl04). Rider (draft vs the `(s8)` cast) is load-bearing.

## Extension: an lb test and an lbu value of the same byte (W81)

The target can test a byte with `lb` and use its value with `lbu` in one function. Test it through `((s8*)obj)[4] == 0`, and read the value as `u8`. A `(s8)obj[4]` cast at the test gives one `lbu` for both.
