# C0219 — Callee result and global base share a register: give each role its own local
tags: codegen,regalloc,local,pointer,call-value,base-pointer,split · date: 2026-10-24 · phase/task: 3.3/T23 · origin: W45 FA4F8

symptom: a callee's returned pointer and a global base are both in the same register (`$5`). The target keeps the result in `a0` and the base in `v0` (18 of 36 words differ).

lever: give each role its own local: `q = func_8002D53C();` for the result, `p = D_8009A1F8;` for the base. One `u8* p` reused for both makes gcc give both lives one pseudo's register choice.
