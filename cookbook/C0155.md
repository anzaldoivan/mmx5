# Inline helper scheduling: block-scoped temps reproduce it

The target showed a helper inlined into its caller. Writing the body inline with its temps in an inner block `{ ... }`
reproduced the inline schedule. The same body with function-scope temps did not, since live ranges change sched/regalloc. Try block scope first when an inlined body's order is off.
