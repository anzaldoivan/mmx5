# C0103 — git check-ignore -q takes one path, so count lines for several
tags: git,firewall · date: 2026-10-11 · phase/task: 2.1/T3 · origin: -

`git check-ignore -q` accepts only one path. Several paths give exit 128.
For several paths, drop `-q`. Then count the output lines. When git ignores all the paths, `git check-ignore a b c | wc -l` equals the path count.
