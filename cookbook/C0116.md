# C0116 — GNU ld: dot inside an output section is a section offset
tags: ld,linker-script,dot,assert,shift · date: 2026-10-12 · phase/task: 2.3/T5 · origin: generalizable

Inside an output section, GNU ld treats `.` as an offset from the section start. `ABSOLUTE(.)` or `ADDR()` in `. =` broke the link. Use literal offsets and `. = MAX(., X)` after an `ASSERT(. <= X)`, so that an overrun names itself.
