# psxd_floor debt --update undercounts while new src files are untracked

- The debt count skips untracked files. If you run `debt --update` before you stage new src/shared or src/<a> files, the baseline comes out low. The commit gate then refuses the commit for a debt rise.
- Fix: stage (git add) the new files first, then run `psxd_floor.py debt --update` alone (R15), then `debt`, then commit. Seen at 3.5 T4.c11.
