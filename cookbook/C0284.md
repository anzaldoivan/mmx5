# C0284 — Second load of a field hoisted above the zero-test branch: read both loads into one s32 local
tags: codegen,sched,sched1,interblock,hoist,load,local,branch,dependence · date: 2026-11-01 · phase/task: 3.4/T11 · origin: W76 FA928_ovl06

symptom: a field is read twice, once for a zero test and once for a bit test in the next block. Ours hoists the second load above the zero-test branch. The target loads it after the branch.

cause: sched1 interblock speculation moves the second load into the dominating block, because it has the same base as the first load. Two separate reads give it no dependence on the branch.

lever: read both loads into one `s32` local: `t = *(s16*)(o + 0x7C); if (t == 0) ...; t = *(u16*)(o + 0x7C); if (!(t & 1))`. The shared pseudo gives the second load output and anti dependences on the first load and the branch. Then sched1 cannot move it.
