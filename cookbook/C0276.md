# C0276 — Identical global RMW tails merged across arms: write the RMW first in one arm
tags: codegen,cross-jump,tail-merge,jump2,rmw,global,statement-order,if-else,regalloc · date: 2026-10-31 · phase/task: 3.4/T7 · origin: W72 F56D8_ovl03

symptom: two arms end with the same read-modify-write of a global (`lbu`, `ori`, `sb`). Ours merges both into one join block. The target keeps one copy per arm, and the `sb` fills the `j` delay slot.

lever: in one arm, write the RMW before a neighbouring store instead of after it. Its registers then differ from the other arm, so gcc does not merge the tails.

## Instance
