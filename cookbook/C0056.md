# C0056 — Invariant load stays at loop head unless the operand is const

## Residual
invariant load at loop head vs hoisted to preheader. tell regex (levers.yaml `loop_const_hoist`): `^\$L\d+:\n\s*lw\s+\$2,%lo\(K\)\(\$\d+\)` — matches ours (before), absent in the after.

## Mechanism
Pass group `loop`; a call in the loop sets unknown_address_altered, so a plain global is not invariant and is reloaded each iteration; RTX_UNCHANGING_P (`const`) is accepted before that test and the load is hoisted. Cite: `gcc/loop.c:3254 RTX_UNCHANGING_P` (staged tree refs/gcc-2.95.2-psx/). Map: docs/codegen-map/loop.md L4.

## Lever
`const`/volatility of the operand: `extern const int K` hoists to the preheader; `extern int K` reloads at the loop head.
