# C0016 — Pinned cross binutils without sudo via dpkg-deb -x
tags: toolchain,binutils,mips,pinning · date: 2026-10-03 · phase/task: 1.3/T1 · origin: -

This procedure needs no sudo. Run `apt-get download` (or use the pool URL) and do the sha256 check. Then run `dpkg-deb -x` into an ignored dir. The result is a pinned cross binutils. Wrap or symlink it into ~/.local/bin. Record the URL and the hash in docs/ops/toolchain.md.
