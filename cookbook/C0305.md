# C0305 — Even value halved loses the sign adjust and grows a frame: early return 0, rest flat
tags: codegen,divide,sign-adjust,sra,srl,even,early-return,block-structure,frame,nonzero-bits · date: 2026-11-02 · phase/task: 3.4/T19 · origin: W84 slus 8003E6FC

symptom: the target computes `v / 2` with `srl 31`, `addu` and `sra 1`, and it has no stack frame. Ours emits a plain `sra 1` and an empty 8-byte frame (`vars= 8`).

cause: `v = t * 6` is provably even, so gcc drops the sign adjust for a signed `/ 2`. Inside `if (v != 0) { ... }` gcc keeps this knowledge. The nested form also grows the frame.

lever: write an early `if (v == 0) return 0;` and keep the rest of the function flat. The block structure breaks the even-value knowledge, and the sign adjust returns.
