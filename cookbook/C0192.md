# C0192 — Same call on two paths merged into one: nest if/else so each arm keeps its call
tags: codegen,cross-jump,tail-merge,jump2,call,nested-if,early-return · date: 2026-10-24 · phase/task: 3.3/T17 · origin: W39 slus 80046984

symptom: two paths call the same callee (`func_X(a0)`). The target keeps a call on each path, the second one last in the function. Ours has one call that both paths jump to.

cause: with early returns, both paths end in the same call-and-return block, and jump2 cross-jumps them into one.

lever: nest the tests as if/else so each arm keeps its own call: `if (A() == 0) { if (B) X(a0); else {...} } else X(a0);`. The else arm's call lands last, as in the target.
