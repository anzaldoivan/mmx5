# C0099 — Constant-address casts live only in include/addr.h as union views
tags: scratchpad,constant-address,raw-cast,addr-h,union,readability · date: 2026-10-11 · phase/task: 1.10/T3 · origin: supersedes C0077 where; T6.c1

This entry supersedes the "where" of C0077. The lever itself stands: a CONST_INT address, never an extern symbol.

## Rule
The matching constant-address cast lives only in include/addr.h. Each absolute address has one `D_<ADDR>`.
include/addr.h defines `D_<ADDR>` as a raw cast to a union (`D_<ADDR>_t`) of the pointee views that read the address.
The name of each member is the lowercased pointee type. The code in src uses `D_<ADDR>.<view>`.
A raw `(T*)0x...` cast in any other place fails `make readability-check` (class `cast`).

## Evidence
The gcc 2.7.2 codegen is byte-identical through the union view. Phase 1.10 T3 (commit ba5d7b7) rewrote 76 sites,
and the fleet `make check` was 2 of 2 green. A union member load is still a CONST_INT address, so the
single-register `lui/lw` of C0077 survives.

## Adding an address
Add the view member in include/addr.h, or add a new `D_<ADDR>_t` union and its define there.
Never add a local `#define` in src.
