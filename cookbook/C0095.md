# Prove a fresh clone in one pass
- Run `git clone <local tree> .run/fc`. Substitute the local path for the public URL. Record the substitution.
- Run the README Build block verbatim. Then, before you fix anything, probe every later gate rung (no-rom, tools-health,
  check) directly in the clone. The probe lists all dev-tree-only dependencies (ignored .run/ state, untracked fixtures)
  at once instead of one rung per rerun.
