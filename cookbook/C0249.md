# C0249 — Second arm placed after the body with a jump back to the test: goto out and goto back (marked !FAKE)
tags: codegen,block-layout,goto,label,if-else,j,FAKE,source-order · date: 2026-10-25 · phase/task: 3.3/T31 · origin: W53 F3040_ovl01

symptom: a two-way value pick feeds one shared test. The target places the second arm after the success block and jumps back to the test. Ours keeps that arm inline before the test, from an if/else, a ternary or swapped arms.

cause: block order follows source order. An arm written before the test is laid out before it.

lever: jump out to a label after the body and jump back to the test label. Write `if (c) goto alt;`, then the first arm, then `test:` and the test. After the body's return, write `alt:`, the second arm and `goto test;`. Mark each goto per C0188. A trailing return-0 label (C0227) often comes with it.

## Instance
W53 F3040_ovl01 (c17), match at try 5. The goto pair took diff 17 to 16 and C0227 then matched. Neighbour F2F8C_ovl01 (c16) took 18 to 3 with the same gotos and failed on a load order.
Related: C0205 (a goto label for block order), C0227 (return-0 block last), C0188 (gate marking).
