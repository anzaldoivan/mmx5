# C0227 — Return-0 block placed last behind blez: goto a trailing none: label (marked !FAKE)
tags: codegen,block-layout,goto,label,return,blez,bgtz,FAKE · date: 2026-10-24 · phase/task: 3.3/T24 · origin: W46 F30A0

symptom: the target tests `<= 0` with `blez` to a `return 0` block placed last in the function. Ours keeps `bgtz` with `return 0` inline, from a plain else, an else-if chain or an early `return 0`.

cause: block order follows source order. An inline `return 0` is laid out where it is written.

lever: jump to a final label: `if (x <= 0) goto none; // !FAKE: goto kept for the matching branch layout`, then end the function with `return 1; none: return 0;`. Mark the goto per C0188.
