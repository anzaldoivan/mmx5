# C0210 — Abs feeding a magic divide: a value ternary keeps one block, the magic lui hoists
tags: codegen,abs,ternary,abssi2,divide,magic,lui,delay-slot,block · date: 2026-10-24 · phase/task: 3.3/T21 · origin: W43 F071C

symptom: an absolute value feeds a magic-number divide. The target keeps one basic block and hoists the `lui` of the magic constant into the `bne` delay slot. Ours splits the block, and the constant loads late (26 words of diff).

lever: write abs as a value ternary, `x = (x < 0 ? -x : x) * 2;`. gcc emits abssi2, a single instruction. Do not write `if (x < 0) x = -x;`.

## Instance
