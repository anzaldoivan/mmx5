# C0330 — Partial sum per arm off its load reg: declare the temp block-scoped in each arm
tags: codegen,regalloc,local-alloc,scope,block,temp,sum,if-else,lui · date: 2026-11-07 · phase/task: 3.4/T27 · origin: W92 slus 800311CC

symptom: an if/else computes the same partial sum in each arm. The target ties the sum to the register of one of its loads. Our build puts the sum in another register.

cause: one function-level temp set in both arms is a global pseudo. A temp declared inside each arm's block lives only in that block. Local-alloc then gives it the register of its load.

lever: if a sum in each arm gets the wrong register, declare its temp inside each arm's block. Do not declare it once per function.

## Instances
W92 slus func_800311CC (c45) matched at try 15 of 20. Each arm declares `s32 t = D_800E9314 + D_800E931C;`. The block-scoped temp closed the last 15 words. An `s16` temp was much worse (49 words). The tail used a fresh `s32` local to read the field before the aliasing store (C0186).
Near: C0155 (block-scoped temps in an inlined helper), C0186 (read before an aliasing store).
