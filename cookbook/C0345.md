# C0345 — Two identical block copies merged by jump2: write the tail's first statement in every arm
tags: codegen,cross-jump,jump2,tail,duplicate,block-copy,label,uid · date: 2026-11-14 · phase/task: 3.5/T2 · origin: W96 F0D3C_ovl24

symptom: the target keeps two identical copies of a block, each ending in `j` to a shared tail. Ours cross-jumps the two copies into one.

lever: write the tail's first statement (here `arg0[1] += 2`) in every arm before the join, the fallthrough arm included. Then jump2 cross-jumps each copy's statement into the fallthrough arm's copy. The redirected jumps target a label new in that pass (UID >= max_uid). So jump2 does not merge the two copies (gcc/jump.c:1981).
