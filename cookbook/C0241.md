# C0241 — Post-decrement with the old value tested via a move copy: a second local, then v-- in place
tags: codegen,s32,decrement,post-decrement,move,copy,local,old-value · date: 2026-10-25 · phase/task: 3.3/T29 · origin: W51 slus 80053444

symptom: an s32 field is post-decremented and its old value tested. The target has `lw v0`, `move v1,v0`, `addiu v0,v0,-1` and `bnez v1`. Ours tests the new value against -1, or loads straight into `v1` with no `move`.

lever: copy the loaded value into a second local, then decrement the first in place. Write `s32 v = x` and `s32 t = v`, then `v--`, `x = v` and `if (t == 0)`.
