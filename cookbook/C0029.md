# C0029 — Filter .L jump-table labels when counting functions from a GNU ld map
tags: ld,map,splat,census · date: 2026-10-05 · phase/task: 1.5/T1 · origin: -

GNU ld maps list splat `.L` jump-table labels as global symbols. Filter `.L`-prefixed names before counting functions from a map, or the function count is inflated (slus: 164 such labels). Origin: phase 1.5 T1, tools/census/inventory.py.
