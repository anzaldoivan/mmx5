# C0193 — Negative mask held in a register for a loop: assign an s32 mask local before it
tags: codegen,regalloc,mask,and,andi,local,constant,loop · date: 2026-10-24 · phase/task: 3.3/T17 · origin: W39 F2AE0

symptom: a field cleared with `and rX,rX,a3` where a3 holds -9 set before a loop. Ours has `andi 0xf7` (u8 field) or `li -9` scheduled after the loop setup.

cause: a literal `~8` is a constant at each use, so gcc emits it late or folds it into `andi`. A local assigned before the loop is a pseudo set at that point, and local-alloc keeps it in a register for the loop.

lever: declare `s32 mask` and assign `mask = ~8` where the target sets the register (here right after the second call), then `p->f &= mask` on the s8 field.
