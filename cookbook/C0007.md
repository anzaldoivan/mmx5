# PS1 XA/STR files are mixed Form 1/Form 2

PS1 XA/STR files are rarely pure Form 2: they interleave Form 1 (video, submode 0x48) and null (0x00) sectors. Classify each sector by subheader submode bit 0x20; keep a 2336-byte payload (raw 16..2351: subheader..EDC) for the whole file.

Cross-check: dumpsxiso -x (mkpsxiso 2.30) writes these files in the same 2336-byte/sector layout, so its output is a direct cmp target. Source: mmx5 phase 1.1 T1, T2; contract docs/formats.md.
