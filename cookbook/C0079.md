# C0079 — Two-way compare storing abs(a-b) per arm: ABS() in each arm folds the negation to b-a
tags: idiom,cse_expr,abs,fold,negate,tail-merge,cross-jump,branch · date: 2026-10-06 · phase/task: 1.8.2/T11 · origin: current/T10 c16

symptom: ABS negation `subu d,b,a` (operands swapped) in the target where ours has `subu d,$0,d`
lever: fold_abs_per_arm

The case is a two-way compare whose arms each store `abs(a-b)` (different operands per arm, same destination). Write `ABS(a-b)` inside each arm, not `d = a-b` per arm and one `ABS(d)` after the join.
With per-arm ABS, the arms cross-jump into one shared ABS tail, and gcc folds `-(a-b)` to `subu d,b,a` (a, b kept live). One ABS after the join negates the difference: `subu d,$0,d`.

Tell: the target's ABS tail is `bgez d` then `subu d,b,a` (operands swapped), not `subu d,$0,d` / `negu`.
Macro: `#define ABS(x) ((x) < 0 ? -(x) : (x))`.
