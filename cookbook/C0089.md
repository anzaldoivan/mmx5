Write the in-place negate of an s16 field as `x *= -1`, not `x = -x`.
`x = -x`: convert_to_integer narrows the NEGATE_EXPR to HImode (only the low half reaches the `sh`), so the load is `lhu`.
`x *= -1`: MULT is not narrowed the same way; the operand is sign-extended to int (`lh`), then the multiply by -1 folds to `negu`.
