# C0089 — s16 field negate: x *= -1 keeps the lh load, x = -x narrows to lhu
tags: idiom,cse_expr,negate,s16,lh,lhu,narrowing,convert · date: 2026-10-07 · phase/task: 1.8.3/T6 · origin: current/T5 c9

symptom: s16 field negated in place: ours `lhu` load then `negu`/`sh`; target `lh` (sign-extending) load then `negu`/`sh`
lever: neg_mul_s16_load

Write the in-place negate of an s16 field as `x *= -1`, not `x = -x`.

`x = -x`: convert_to_integer narrows the NEGATE_EXPR to HImode (only the low half reaches the `sh`), so the load is `lhu`.
`x *= -1`: MULT is not narrowed the same way. The operand is sign-extended to int (`lh`). Then the multiply by -1 folds to `negu`.

Tell: the target has `lh $r,off(base)` that feeds `negu`/`subu $r,$0,$r` and `sh` back to the same offset.
