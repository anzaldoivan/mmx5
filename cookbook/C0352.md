# A change to a [own] file needs the developer's protected raise before its commit

- `config/psxdecomp.toml` `[own]` names files that carry the floor (`campaign = tools/wave/ledger.py`, the debt scanner, the gate, the matcher kit).
- Committing a change to one fails with `GATE FAIL protected: <file> changed`.
- To allow it, run `PY tools/psxd_floor.py debt --raise protected 1 --reason "<why>"`. It refuses under CLAUDECODE (psxd_floor.py:1512), so the developer runs it.
- After the raise, commit with `config/debt-baseline.txt` among the paths.
- When a task's files include an [own] path, leave the coder run green and uncommitted.
- Then return `blocked` with the exact raise and commit commands. Finish after the developer commits (3.5 T5).
