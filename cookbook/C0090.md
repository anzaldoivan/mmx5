# Glob-then-read scans over a tree other agents write
- A scan that globs and then reads files that another process may delete must skip `FileNotFoundError` per file, not abort.
- Shared scratch worktrees take a per-process path (`.run/carve/wt-<pid>`), and each process cleans only its own.
- Seen: parallel `shapes.py check` and carve worktrees raced in waves (1.8.2 T10-T14). 1.8.3 T1 fixed the race (tools/dedup/README.md).
