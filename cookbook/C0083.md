# Reused build worktree keeps stale splat outputs
- splat never deletes outputs that it no longer writes. A reused worktree keeps the old per-subsegment `.s`.
- When a subsegment changes its type (asm -> c, textbin -> rodatabin), delete its `.s` before the rebuild.
