# Re-export tracked Ghidra exports after a rename

After you rename symbols in the Ghidra project (tools/readability/mirror.py apply), re-export each tracked export
that tools/ghidra/roundtrip.sh compares (docs/oracle/annotations.jsonl). Do this in the same change. Otherwise, the
roundtrip goes red. mirror.py apply does this when it changed a name (Phase 1.10 T5).
