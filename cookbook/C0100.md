# Scratchpad pointer as a union of views

gcc 2.7.2 emits byte-identical code for `(*(U*)0xADDR).member`, where `U` is a union of pointer types, and for
`*(T**)0xADDR`. Phase 1.10 T3 verified this across 76 sites (clean fleet `check: 2 of 2 green`).

If the code reads one absolute address (e.g. scratchpad 0x1F80004C) through several pointee types, name the address
once in include/addr.h. The name is `D_<ADDR>`, a union with one member for each view. Access the address as
`D_<ADDR>.<view>`. Use no second cast in any place.
This entry supersedes the "where" of C0077 (see C0099).
