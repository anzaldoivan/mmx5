# C0023 — break encoding tells the assembler: GNU 0x0007000D vs aspsx 0x000001CD
tags: aspsx,maspsx,psx,fingerprint · date: 2026-10-04 · phase/task: 1.4/T3 · origin: phase-ends/current/tasks/T3.md

Division-trap break encoding identifies the assembler: 0x0007000D is GNU as `break 7`; 0x000001CD is aspsx/maspsx `break 0x0,0x7`. Count each in target code to tell asm-from-GNU vs aspsx output. Source: 1.4/T3.
