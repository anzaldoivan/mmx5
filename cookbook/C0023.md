# C0023 — break encoding tells the assembler: GNU 0x0007000D vs aspsx 0x000001CD
tags: aspsx,maspsx,psx,fingerprint · date: 2026-10-04 · phase/task: 1.4/T3 · origin: phase-ends/current/tasks/T3.md

The division-trap break encoding identifies the assembler. 0x0007000D is GNU as `break 7`, and 0x000001CD is aspsx/maspsx `break 0x0,0x7`. Count each encoding in the target code to tell asm-from-GNU output from aspsx output. The source is 1.4/T3.
