# `x >> 2` for `x / 4` when x is known non-negative
- gcc emits a sign fix-up (bltz/addiu or srl+addu) for signed `/ 4`. For x >= 0, `>> 2` is identical and shorter.
- Useful when a patch must not grow the function (shifted build region slack).
