# C0197 — Two bytes of a table row with separate address adds: D[r*2] then (&D[r*2])[1], no table local
tags: codegen,array,address,addu,cse,table,lbu,cross-jump · date: 2026-10-24 · phase/task: 3.3/T18 · origin: W40 FE5BC

symptom: two bytes of a table row are read with two separate address adds (`addu off,tbl` and `addu tbl,off`). Ours shares one address or adds `off+1` first.

cause: `D[r*2+1]` folds the `+1` into the index add. A table pointer local lets cse fuse both addresses.

lever: read the first byte as `D[r*2]` and the second as `(&D[r*2])[1]`. Name the table symbol in each arm, with no table pointer local.

## Instance
W40 FE5BC_ovl04: a table pointer local (u8*, u8(*)[2], struct) gave diff 13 of 43. The `(&D[r*2])[1]` form with a table per arm matched at try 9.
Related: C0050 (cross-jump law), C0190 (row tables).
