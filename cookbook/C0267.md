# C0267 — Abs test as bgez, nop, negu with the constant hoisted: write __builtin_abs(x) > C
tags: codegen,abs,abssi2,builtin,bgez,negu,compare · date: 2026-10-31 · phase/task: 3.4/T5 · origin: W70 F1958_ovl11

symptom: the target tests an absolute value with `bgez`, `nop` and `negu`. The `lui` of the compare constant comes before the `bgez`. A two-sided compare `x > C || x < -C` or a condition ternary (C0080) gives a different block. A value ternary abs gives the same code as the builtin.

lever: write `__builtin_abs(x) > C`. gcc 2.95 then emits its MIPS `abssi2` pattern. The constant load moves above the branch.
