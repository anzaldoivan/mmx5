# C0340 — Tested value copied in the beqz delay slot: test into its own s32 local first, reuse the source
tags: codegen,delay-slot,copy,coalesce,cse,combine,local,compare,sltiu,regalloc · date: 2026-11-14 · phase/task: 3.5/T2 · origin: W96 slus 8002B070

symptom: the target loads a field into v1, tests it, and copies it to a1 in the `beqz` delay slot. Every plain `c = e` form gets coalesced by cse `make_regs_eqv` or combine, so the copy vanishes.

lever: compute the test into its own s32 local (`ok = (u32)e < K;`) BEFORE the copy `c = e`. Then reuse `e` (s32) for a later read (`e = *(s16*)(p + 6)`). `e` and `c` now conflict and stay apart, so the copy survives in the slot. Keep `c` s32 (u8 gives `andi 255`). The u32 cast keeps `sltiu`.
