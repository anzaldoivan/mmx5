# Decrement-and-test of a u16 field: s32 temp, test `(s16)t`

Target decrements a u16 field, stores it back, and tests the result through a 16-bit sign shift (`sll 16`, then `bnez`). A `u16` temp for the decremented value gives diff 4/30 in rockx5 func_800EFB20_ovl03.

Write `s32 t = *(u16*)(p + off) - 1;`, store `t` back to the field, and test `if ((s16)t == 0)`. Later tests of the same value (`t & 1`) read `t` directly.

Related: a field declared `s16` instead of `u16` gave the same shift test in rockx5 func_800EFBF8_ovl29 (W25). That row carries no credit because the fix is a type fact.

Rider: harvest.py rider (draft vs `u16 t` with `t == 0`) is load-bearing (.run/w25/c50/).
Source: 3.3 T3 W25 (draft coder c2 report: a u16 temp gave diff 4 of 30 words, and `s32 t` with `(s16)t == 0` matched).

## Extension: three more decrements (W87)

In slus func_80036488 (c31), the byte form works the same way. Write `t = arg0[0x8A] - 1; arg0[0x8A] = t; if ((t << 24) == 0)` with `s32 t` for a lone `sll 24`. An `s8 t` temp gave `sll` plus `sra`.

In rockx5 func_800FB308_ovl38 (c29), the temp is `u16 t`. If the temp is `u16`, write the test as `(t << 16) == 0`. The test `(s16)t == 0` gave `andi 0xffff`.
