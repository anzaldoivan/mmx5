# GNU ld gotchas for a relinkable exe+overlay pair
- The shift scanner counts an ABS linker symbol as unsymbolized. For an exe-defined region start, use an empty output section at an offset from a bss-end symbol: ld drops the section, the symbol stays section-relative. (2.4/T4.1)
- Once the exe ELF defines overlay names, `--just-symbols` of it in the overlay link gives multiple definitions. Link against a copy with those names localized (`objcopy --localize-symbols`). (2.4/T4.1)
- This binutils rejects `ASSERT(...);` with a trailing semicolon at SECTIONS level. Emit it without the semicolon. (2.4/T5)
