# C0198 — Stored byte sum tested for zero with a lone sll 24: test the field through an s8 view
tags: codegen,s8,u8,zero-test,sll,andi,store,view · date: 2026-10-24 · phase/task: 3.3/T18 · origin: W40 F9C08

symptom: a byte sum is stored to a field and then tested for zero. The target has a lone `sll 24` before the `bnez`. Ours has `andi 0xff` (u8) or `sll` plus `sra` (s8 local).

cause: the test reads the value the store just wrote. Through an s8 view only the low byte matters, so gcc emits the shift alone.

lever: store the sum to the field, then test the field through an s8 view: `((s8*)a0)[0x5C] == 0`. Use no local for the sum.

## Instance
W40 F9C08_ovl27: a u8 local gave diff 3, an s8 local 14, the u8 field test 1 word. The s8 view of the stored field matched.
