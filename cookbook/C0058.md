## Residual
The residual is a recompute where the target reuses, with no label/call between. The tell regex (levers.yaml `cse_volatile_asm_flush`) is `^\s*sll\s+\$2,\$3,3`. It matches ours (before) and is absent in the after.

## Mechanism
The pass group is `cse_expr`. The cse pass reuses an identical expression within the block. An operand-less, clobber-less volatile asm is a raw ASM_OPERANDS, and cse flushes its whole table there. A basic `asm("")` and a "memory" clobber do not flush register classes. Cite: `gcc/cse.c:7697 flush_hash_table` (staged tree refs/gcc-2.95.2-psx/). Map: docs/codegen-map/cse_expr.md K§1-g.

## Lever
To force the recompute, insert `__asm__ __volatile__("" : : );` between the occurrences (zero bytes). When only one value must recompute, prefer a re-tie (cse_call_retie).
