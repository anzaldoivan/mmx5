# rodata-shared carve: plan with the draft text, extern-reached rodata stays in the region

carve.py `plan` refuses `rodata-shared` when another function also references a range in the region. A span that the C reaches only through `extern` gets no bytes from the object, so the SHA goes red.

Since 2.8 T10.c2, `carve.plan` takes the draft text (`ctext`). The gate and reconcile pass it. A ref that the C declares `extern` stays in the region sub and is not carved. Game strings never go into C (G12).
