# Global array kept in a register across a branch: load its address into a local pointer

Target loads a global array's address once and keeps it in an argument register across a branch, then stores through it again inside the branch. Writing `D[...]` at each access gives diff 17 in rockx5 func_800FA588_ovl44.

Write `u8* p = D;` at the top and access every field through `p`. The second access then reuses the register instead of rebuilding the address.
