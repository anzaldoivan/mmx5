# C0077 — Scratchpad pointer load: raw constant-address cast, never an extern symbol
tags: idiom,cse_expr,scratchpad,1F80004C,constant-address,hi-lo-split,raw-cast,extern · date: 2026-10-06 · phase/task: current/T7 · origin: docs/codegen-map/levers.yaml addr_const_scratchpad

symptom: scratchpad pointer load shifted one register: target `lui $vN,0x1F80; lw $vN,0x4C($vN)` (same reg), ours `lui %hi(sym)` / `lw %lo(sym)` in two regs
lever: addr_const_scratchpad

## Residual
A load of a PSX scratchpad pointer (`0x1F80004C`) written as `extern T *D_1F80004C;`. tell regex (levers.yaml `addr_const_scratchpad`): `%hi\(D_1F80004C\)` -- matches ours (before), absent in the after. In game fns the extra HIGH pseudo costs one register shift in the following code (rockx5 func_800F0E04_ovl28, func_800F5018_ovl26: no extern form matched under the pin).

## Mechanism
Pass group `cse_expr` (address legitimization). A SYMBOL_REF address satisfies `mips_check_split` (`gcc/config/mips/mips.c:1191`, staged tree refs/gcc-2.95.2-psx/), so it is split into a HIGH pseudo plus a LO_SUM load; local-alloc gives the two pseudos two registers. A CONST_INT address is not split: cc1 emits one `lw $3,528482380` and the assembler macro expands it through the dest register (`lui $3,0x1f80; lw $3,0x4c($3)`).

## Lever
`#define D_1F80004C (*(T **)0x1F80004C)` -- a raw constant-address cast, never an extern symbol. shapes.py accepts it; precedent in banked src (src/shared/func_800F0F18_ovl28.c). Applies to any `0x1F80xxxx` scratchpad load whose target uses the same register for the lui and the lw.
