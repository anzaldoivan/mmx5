# C0216 — Byte-clear loop with all regs shifted by one: store a zero local (z = 0), not literal 0
tags: codegen,regalloc,loop,zero,local,sb,byte-clear · date: 2026-10-24 · phase/task: 3.3/T22 · origin: W44 slus 8002CF70 8002DC44

symptom: a byte-clear loop (`*p++ = 0`) has every reg shifted by one against the target (37 of 37 words). The target keeps 0 in a reg (`addu a3,zero,zero` at entry, then `sb $a3`). Ours stores `sb $zero`.

lever: hold the stored zero in a local set before the loop. Write `u8 z = 0;` or `s32 z = 0;`, then `*p++ = z;`.
