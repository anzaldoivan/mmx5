# Identify a PsyQ SDK release from its headers
- grep the headers for `$PSLibId: Run-time Library Release x.y`.
- Archive names and CC1PSX banners mislead (a 4.4 SDK shipped a gcc 2.95.2 CC1PSX).
- bsdtar (linuxbrew) reads .7z, so you need no 7z binary.
