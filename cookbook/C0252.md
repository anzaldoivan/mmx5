# C0252 — Table index by the sign of an s8 local gives slt/subu: write i >> 31, not i >> 7
tags: codegen,s8,sign,shift,sra,index,table,lb · date: 2026-10-25 · phase/task: 3.3/T33 · origin: W55 F016C_ovl24

symptom: an s8 local, known to be 0 in the arm, indexes a table by its sign. The target emits one `sra 31` on the lb value. Ours emits an `slt`/`subu` pair.

lever: write the sign index as `i >> 31`, not `i >> 7`. The lb value is already sign-extended to 32 bits, so gcc folds the shift into one `sra 31`.

## Instance

With `i >> 7` the diff was 14 of 21 words.
