# C0025 — aspsx versions tie unless a maspsx gate fires on the binary's shapes
tags: aspsx,maspsx,compiler-pin,probe · date: 2026-10-04 · phase/task: 1.4/T4 · origin: phase-ends/current/tasks/T4.md

An aspsx version is only discriminable where a maspsx version gate (refs/maspsx/maspsx.py config_for_aspsx_version) fires on shapes the binary actually has. Before adding probes to split aspsx versions, check which gates fire against tell counts in the target; otherwise several versions tie. Source: 1.4/T4.
