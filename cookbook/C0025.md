# C0025 — aspsx versions tie unless a maspsx gate fires on the binary's shapes
tags: aspsx,maspsx,compiler-pin,probe · date: 2026-10-04 · phase/task: 1.4/T4 · origin: phase-ends/current/tasks/T4.md

An aspsx version is only discriminable where a maspsx version gate (refs/maspsx/maspsx.py config_for_aspsx_version) fires on shapes that the binary actually has. Before you add probes to split aspsx versions, check which gates fire against the tell counts in the target. Otherwise, several versions tie. The source is 1.4/T4.
