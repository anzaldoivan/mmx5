# C0111 — splat bss subsegment emits an empty .s unless ld_bss_is_noload is set
tags: splat,bss,noload,yaml · date: 2026-10-12 · phase/task: 2.3/T2 · origin: generalizable

A splat `bss` subsegment produces an empty .s (no symbols, no size) unless the yaml sets `ld_bss_is_noload: True`.
