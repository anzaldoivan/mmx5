# C0233 — Byte field tested by an outer and an inner if: read it once into a u8 local
tags: codegen,u8,local,lbu,reload,cse,nested-if,mask · date: 2026-10-25 · phase/task: 3.3/T26 · origin: W48 slus 800477E4

symptom: a byte field is tested by an outer and an inner if. Ours reads it at each test (two `lbu`), the target loads it once. W48 slus 800477E4 try 1 (`if (a0[0x8C] & 8) { if (a0[0x8C] & mask) ...`) had diff 25 of 32 words.

lever: read the field once into a `u8` local before the outer test. Test the local in both ifs: `u8 flags = a0[0x8C]; if (flags & 8) { if (flags & mask) ... }`. gcc keeps one `lbu`, and the registers of the rest shift to the target's.

## Instance
W48 slus 800477E4 (c8): the `u8 flags` local matched at try 2. The mask before it is the C0209 shape (`mask = 2; if (a0[0x15] != 0) mask = 1;`).
Related: C0183 (one s8 local for a compare and a store), C0178 (a local placed where the target loads).
