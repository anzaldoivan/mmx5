# C0338 — Inline helper with a table pointer param shares one addu: index the global at every use
tags: codegen,inline,helper,macro,table,2d,cse,address,addu · date: 2026-11-07 · phase/task: 3.5/T1 · origin: W95 FCDD0_ovl07

symptom: a spawn block repeated at several call sites reads a global `s16 D[][2]` row twice. The target has two separate addu per site (idx+base, then base+idx). A static inline helper with a pointer param (`s16*` or `s16 (*)[2]`) CSEs the row address into one addu.

lever: write the table reads out at every use, `D[o[2] & 0x1F][0]` and `D[o[2] & 0x1F][1]`, re-indexing the global each time. A macro gives the same bytes. The banked body has the macro expanded.

## Instance
W95 rockx5 func_800FCDD0_ovl07 (c36): helper 236 words over 5 tries, per-use reads 106 words. Then C0069, C0182 and C0194 closed it.
generalizable: a pointer param of an inlined helper lets cse share the table address.
Near: C0166 (index the global each time), C0212 (inline helper for a constant address).
