# C0209 — Flag set by either of two tests: hit = 0, then one if per test sets hit = 1
tags: codegen,flag,local,compare,sltu,delay-slot,regalloc,if · date: 2026-10-24 · phase/task: 3.3/T21 · origin: W43 slus 8004F4E0

symptom: a flag is set by either of two tests. With `hit = (A) == x; if (B) hit = 1;` the `sltu` lands in a `bne` delay slot, and v0/a0/v1 are rotated against the target (32 of 39 words). `if (A || B)` is worse (36).

lever: start the flag at zero and set it in two separate ifs: `hit = 0; if (A) hit = 1; if (B) hit = 1; if (hit) ...`.
