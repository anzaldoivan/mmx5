# C0031 — splat textbin: leave interior symbols untyped
tags: splat,textbin,symbols,link · date: 2026-10-05 · phase/task: 1.5/T2.1 · origin: -

A splat `textbin` subsegment defines only its start symbol. Symbols at interior addresses must stay untyped in symbols.<alias>.txt so undefined_syms_auto defines them. If you type them, the link breaks with undefined references. Origin: phase 1.5 T2.1.
