# Trace the forced branch before declaring a behaviour patch
- A patch can force or change one arm of a branch. It is a silent no-op if the oracle input never takes that arm (or the condition is already true).
- Before declaring, set an Exec bp at the function entry on the oracle (replay) input and log the fields the condition tests. Confirm that the patched arm is reached.
- Watching only the write the patch should change is not enough (2.5 T4: 0 divergences, then T4.1 re-targeted the halve arm).
