# C0021 — gcc 2.x cc1 has no --version: use -version </dev/null
tags: gcc,cc1,toolchain · date: 2026-10-04 · phase/task: 1.4/T1 · origin: phase-ends/current/tasks/T1.md

In gcc 2.x, `cc1 --version` exits 33. Use `cc1 -version </dev/null`, which exits 0 and prints the banner. The sources are 1.4/T1 and docs/ops/toolchain.md:25.
