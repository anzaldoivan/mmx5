# C0010 — Ghidra headless rejects '.'-leading project path elements
tags: ghidra,headless,paths · date: 2026-10-03 · phase/task: 1.2/T2 · origin: phase-ends/current/tasks/T2.md

- analyzeHeadless refuses a project path containing any element starting with '.' (e.g. .run/).
- Workaround: symlink a plain dir (ghidra/rt-proj -> .run/ghidra-rt/proj) and pass the symlink.
