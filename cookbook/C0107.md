# C0107 — PCSX-Redux 298: Lua listener stack leak, recycle fix
tags: pcsx-redux,lua,listener,replay · date: 2026-10-12 · phase/task: 2.2/T3.1 · origin: phase-ends/current/tasks/T2.md:26 phase-ends/current/tasks/T3.1.md:26-27

Redux 298 Lua event listeners leak 2 stack slots per dispatch on their own thread. After ~32736 events (vsync 32736 for a per-vsync listener), Lua errors with stack overflow. Then the next stdout line is lost.

To fix this, recreate the listener periodically (every 16384 vsyncs). Remove the old listener from inside the callback of the new listener. A listener that an event callback creates fires in that same dispatch. Thus, guard per-vsync work with `PCSX.getCPUCycles()`. Skip the work when the value is unchanged. The source is tools/replay/replay.lua (phase 2.2 T3.1), R2.2-001.
