# GCC sources: split on \n only
GCC sources contain form feeds (\f). Python `str.splitlines()` splits on \f too, so line numbers drift from grep's.
Use `text.split("\n")` when resolving `file:line` citations. Source: phase T1 (tools/codegen/cites.py).
