# C0271 — Remainder after a divide copies the quotient: write n - q * 100, not n % 100
tags: codegen,modulo,divide,quotient,move,copy,regalloc · date: 2026-10-31 · phase/task: 3.4/T6 · origin: W71 F428C_ovl24

symptom: the target computes `n / 100` and then the remainder from the same quotient register. Ours has an extra `move` copy of the quotient. A later value also lands in the wrong argument register.

lever: write the remainder as `n - q * 100`, with `q` the quotient local. Do not write `n % 100`. Then gcc reuses the quotient register and adds no copy.

## Instance
W71 rockx5 func_800F428C_ovl24 (c38) draws three digits of a counter. Tries 1 and 2 with `n % 100` had a diff of 58 of 105 words. Try 3 with `tens = n - hundreds * 100` matched.
A local `n` instead of direct global reads had no effect.
Related: C0239 (a callee result modulo a constant).
