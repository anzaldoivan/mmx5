# C0343 — Epilogue restore hoisted into the last load slot: per-arm stores, then x++ and a bare return
tags: codegen,sched2,epilogue,return,fence,cross-jump,jump2,store,per-arm · date: 2026-11-14 · phase/task: 3.5/T2 · origin: W96 slus 8004B49C

symptom: an epilogue restore (`lw ra`/`lw s`) is hoisted into the final `lbu` delay slot, or above an `sh`. The target keeps the restores below the arm's stores.

lever: end each arm with its own stores, then `x++; return;` (`if (c) sh A; else sh B; obj[4]++; return;`). The return label fences sched2, and jump2 cross-jumps both `x++` tails. A ternary or a select local lets the `lbu` hoist above the `sh`, so only two insns merge.
