# C0048 — Phantom callee-saved from cross-call CSE: re-tie the value per call

## Residual
a phantom callee-saved register. tell regex (levers.yaml `cse_call_retie`): `^\s*andi\s+\$16,\$4,0xffff` — matches ours (before), absent in the after.

## Mechanism
Pass group `cse_expr`; cse keeps a pseudo-held class across calls (only call-clobbered hard regs are invalidated), so `x & 0xffff` is computed once and parked in a callee-saved reg ($s0) for the second call. Cite: `gcc/cse.c:1962 regs_invalidated_by_call` (staged tree refs/gcc-2.95.2-psx/). Map: docs/codegen-map/cse_expr.md K§3.

## Lever
a zero-byte input-tied re-tie `__asm__("" : "=r"(x) : "0"(x));` between the occurrences re-SETs x, every class built from x goes stale, and the expression is recomputed at each use.
