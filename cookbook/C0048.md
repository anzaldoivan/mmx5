# C0048 — Phantom callee-saved from cross-call CSE: re-tie the value per call

## Residual
The residual is a phantom callee-saved register. The tell regex (levers.yaml `cse_call_retie`) is `^\s*andi\s+\$16,\$4,0xffff`. It matches ours (before) and is absent in the after.

## Mechanism
In pass group `cse_expr`, cse keeps a pseudo-held class across calls (a call invalidates only call-clobbered hard regs). Thus the compiler computes `x & 0xffff` once and parks the value in a callee-saved reg ($s0) for the second call. Cite: `gcc/cse.c:1962 regs_invalidated_by_call` (staged tree refs/gcc-2.95.2-psx/). Map: docs/codegen-map/cse_expr.md K§3.

## Lever
A zero-byte input-tied re-tie `__asm__("" : "=r"(x) : "0"(x));` between the occurrences re-SETs x. Every class built from x goes stale, and the compiler recomputes the expression at each use.
