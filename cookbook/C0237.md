# C0237 — Pointer table indexed by two bytes with one shift: flat D[c*2+d], not 2-D D[][2]
tags: codegen,array,table,index,sll,flat,2d,address · date: 2026-10-25 · phase/task: 3.3/T28 · origin: W50 slus 80047184

symptom: a pointer table indexed by two bytes gives `sll 3` for the row and `sll 2` for the column. The target computes `(c*2 + d) << 2` with one shift.

lever: declare the table flat, `extern u32* D[]`, and index it as `D[c * 2 + d]`. A 2-D `D[][2]` scales each index on its own.

## Instance
W50 slus 80047184 (c13): `extern u32* D_800730AC[][2]` read as `D[c][d]` gave diff 5 of 29 words. The flat table with `[c * 2 + d]` matched at try 2.
Related: C0190 (the opposite case, where 2-D rows match), C0197 (two bytes of a flat row).
