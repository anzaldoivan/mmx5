# Else-if with the body written twice reproduces a second field load

Target re-loads a field (`lb unk2`) at the second test of a two-arm condition. One `||` condition (or nested early return, goto) lets cse reuse the first load: diff 20/31 in rockx5 func_800FD048_ovl39.

Write `if (A) { body; } else if (B) { body; }` with the body written twice. Each arm is its own block, so the field is loaded again. Then jump2 cross-jumps the two identical bodies into one, so the output has one body.

Rider: harvest.py rider (draft vs one `||` condition) is load-bearing (.run/w24/c50/).
