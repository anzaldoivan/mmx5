# C0190 — Table of 6-byte rows read at +2/+4: declare s16 D[][3], read D[i][k] inline
tags: codegen,array,2d,row,struct-array,address,lh,lo-fold · date: 2026-10-24 · phase/task: 3.3/T17 · origin: W39 F7BEC

symptom: a table of 6-byte rows read at +2 and +4. The target forms the row address with `addu a0,base,off`, copies it (`addu v1,a0,zero`) and loads `lh 2(a0)` / `lh 4(v1)`. Ours folds +2 into `%lo(D+2)` or orders base and offset differently.

cause: a flat `*(s16*)(D + i*6 + 2)` lets gcc fold the field offset into the symbol. A local pointer changes the operand order. A 2-D array row is the same RTL as a struct-array member access.

lever: declare `extern s16 D[][3]` and read `D[i][1]`, `D[i][2]` inline, no local. This gives the struct-array codegen without a struct type (readability scan refuses stray structs outside include/).
