# C0236 — Switch whose cases all return -1: return in each case, not break plus one shared return
tags: codegen,switch,case,return,tail,cross-jump,block-layout · date: 2026-10-25 · phase/task: 3.3/T28 · origin: W50 slus 80031508

symptom: a switch whose cases all return the same value has the wrong case-body order and tail. The target shares one `sb; jr ra; li v0,-1` tail that the other cases jump into.

lever: write `return -1` at the end of each case, not `break` plus one shared `return -1` after the switch. Put the default's `return 0` after the switch.

## Instance
W50 slus 80031508 (c8): a switch on a u8 over cases 0x38 to 0x3F. With `break` and one `return -1` after the switch, the diff was 18 of 29 words. Per-case returns matched at try 2.
Related: C0072 (case order), C0161 (shared case bodies), C0175 (early-return layout).
