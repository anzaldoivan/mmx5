# splat/spimdisasm gotchas when symbolizing overlay data
- In a yaml whose only non-overlay segment has no vram, spimdisasm treats rom 0x0-0x1000 as its default global segment. Give that segment a vram.
- A data word can never reference a `type:label`. Use an `alabel` inside a sized `type:func`, or splat `reloc_addrs` per site.
- `reloc_addrs` type strings take no `R_` prefix (`MIPS_32`). GNU as rejects `(sym >> 16)` on an extern. Use HI16 with an addend for lui/ori.
- Subsegs under 4 bytes typed `data` emit nothing (bytes lost, SHA red). Keep them `databin`.
