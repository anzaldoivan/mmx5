# C0201 — Every call arg narrowed lhu+sll/sra: declare the callee's params s32, not the s16/u8 consensus
tags: codegen,callee-decl,prototype,param,s16,s32,narrowing,lh,lhu · date: 2026-10-24 · phase/task: 3.3/T19 · origin: W41 EED00

symptom: every argument to one call is loaded `lhu` then narrowed with `sll 16; sra 16` (or `andi 0xFF`). The target loads `lh` and adds with a plain `addiu`, no narrowing.

cause: the callee is declared with `s16`/`u8` parameters. gcc converts each argument to the parameter type at the call. With `s32` parameters there is no conversion.

lever: declare the callee with `s32` parameters, even when other units declare it narrower: `void func_8002B070(s32, s32, s32, s32, s32);`.

W41 EED00_ovl02: the consensus `(s16, s16, s16, s16, u8)` gave diff 36/42 words. All-`s32` params matched.
