# C0142 — Validate pack header arithmetic before naming a format
tags: formats,survey,containers · date: 2026-10-18 · phase/task: 2.6/T1 · origin: -

Problem: a histogram of each member's first u32 reads count-led packs as file magics (0x10 = a 16-entry pack header, not a TIM magic).
Technique: before naming a format, check the header arithmetic: for a pack, total == 2048 + sum(align2048(size_i)). A format is named only when the arithmetic holds for every member.
Evidence: phase 2.6 T1 (tasks/T1.md:22). ROCK_X5.DAT 165 packs, 0 TIM.
