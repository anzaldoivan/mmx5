# C0254 — If-chain result built in a1 then moved to v0: return in place in every arm, no result local
tags: codegen,return,local,v0,regalloc,if-else,early-return · date: 2026-10-25 · phase/task: 3.3/T33 · origin: W55 F09A0_ovl07

symptom: an if-chain picks a return value, and ours computes it in a1 and moves it to v0. The target builds the value in v0 in each arm.

lever: return in place in every arm. Do not set a result local and return it once at the end.

## Instance
W55 rockx5 func_800F09A0_ovl07 (c39), match at try 3. The result-local form gave 3 diff words with the value in a1.
A switch with GNU case ranges built a jump table here (23 of 20 words). So C0251 does not hold at this case density.

Related: C0236 (per-case return in a switch), C0175 (early-return layout).
