# Overlay region RAM bound from exe constants
- The bound of an overlay region is the lowest fixed exe RAM constant above the largest member (grep lui/ori constants + undefined_syms_auto). In mmx5 it is the CD sector/image buffer base 0x80105000.
- A member that already overlaps another region in retail proves it is never co-resident with that region. Members that end below the other region's start get the tighter co-residency bound.
