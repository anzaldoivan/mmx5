# C0176 — u8 parameter shifted once and stored: write the shift per store, not a reassignment
tags: codegen,u8,param,shift,truncation,cse,store · date: 2026-10-20 · phase/task: 3.3/T9 · origin: W31 17E98

symptom: a u8 parameter is shifted once and stored several times. `vol >>= 1;` and plain stores of `vol` re-truncate the u8 and change the register flow.
lever: leave the parameter alone and write `vol >> 1` in each store.

## Residual
W31 slus func_80017E98: `vol >>= 1;` then four `D_800E8058[i] = vol;` gives diff 7 of 31 words.

## Lever
`D_800E8058[0] = vol >> 1; ... D_800E8058[3] = vol >> 1;` matched. gcc CSEs the shift into one register. Reassigning the u8 parameter adds a truncation to 8 bits that the target does not have.
