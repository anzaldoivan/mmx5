# C0195 — Undoing an uncommitted gate run: make split build before re-gating, else not-found
tags: workflow,gate,undo,split,asm,not-found,config · date: 2026-10-24 · phase/task: 3.3/T17 · origin: T17.c49 W39 gate

symptom: after undoing an uncommitted gate run (config restored), re-gating the target refuses with not-found.

cause: the gate run carved the function out of asm/. Restoring the config does not restore the carved asm.

lever: after restoring config, run `make split build BINARY=<alias>` before re-gating.

## Instance
T17.c49 (W39 gate): undo of a failed rockx5 gate run, the re-gate refused not-found until split and build ran again.
