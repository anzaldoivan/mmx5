# C0282 — Constant test gives li and bne, the target has xori and bnez: XOR into the result local
tags: codegen,xor,xori,bnez,compare,constant,local,call-value · date: 2026-11-01 · phase/task: 3.4/T10 · origin: W75 slus 80038388

symptom: a call result is tested against a constant. The target has `xori` and `bnez`. Ours has `li` and `bne`, because a `!=` test loads the constant into a register.

cause: The compiler keeps a written `^` as one `xori`. A plain `!=` compare becomes `li` plus `bne`.

lever: write the XOR into the result local, then test the local: `in = f(a0) ^ 0x2E; if (in) return 0;`.

## Instance
