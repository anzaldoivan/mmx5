# C0026 — Absolute low-address loads: use T *p = 0; p->field, not *(int *)addr
tags: gcc,matching,c-idiom · date: 2026-10-04 · phase/task: 1.4/T4 · origin: phase-ends/current/tasks/T4.md

`*(int *)0x110` read in a loop is hoisted by every gcc 2.x cc1 as `li reg,272` + base. To keep `lw rd,0x110($zero)` write `T *p = 0; p->field`. Source: 1.4/T4.c1.
