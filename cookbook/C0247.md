# C0247 — Two-constant select into one field: store the ternary directly, not a preset local
tags: codegen,ternary,select,store,local,v0-v1,sched · date: 2026-10-25 · phase/task: 3.3/T30 · origin: W52 FB5BC_ovl27

symptom: a two-constant select stored to a field puts the value in `a1` and schedules the `sw` after the `li` pair. The target uses v0 and stores first.

lever: store the ternary directly, `*(s32*)(a0 + 0x20) = c ? -0x4000 : 0x4000`. Do not preset a local and reassign it in an `if`.
