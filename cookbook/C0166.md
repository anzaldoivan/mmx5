# C0166 — Element address recomputed per use: index the global each time, no cached element pointer
tags: codegen,cse,address,global,index,row,cached-pointer · date: 2026-10-20 · phase/task: 3.3/T6 · origin: W28 8002D938 FEC84

symptom: target recomputes the element or row address (`addu` of base and index) at each use. Ours computes it once.
lever: index the global at each use (`D[i].f`, `D[i][k]`). Do not cache `&D[i]` in a local pointer.

This includes the shared `t0 + a1` row address in a second block.
