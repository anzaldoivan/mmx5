# levers tell regex: allow .set lines before branches
maspsx/cc1 emit `.set noreorder` / `.set` lines between the last insn and a branch in `.cc.s`.
A tell regex must not assume adjacent lines across a branch: use single-line tells or allow `.set` lines. Source: T4.
