# Dockerfile RUN globs run under dash
A Dockerfile `RUN` glob `**/*.c` runs under /bin/sh (dash, no globstar), so it means `*/*.c`.
When replicating Dockerfile steps in bash, reproduce the dash semantics, not bash globstar. Source: T1 stage.sh.
