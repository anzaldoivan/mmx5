# C0235 — Unknown-trip loop form (li n, blez, bnez down-counter): write the bound as end - p with a named end
tags: codegen,loop,bound,blez,bnez,trip-count,cse,end-pointer · date: 2026-10-25 · phase/task: 3.3/T28 · origin: W50 slus 8001DB78

symptom: the target asm of an inner counted loop is `li n`, `blez n`, `move cnt,n`, then `bnez cnt`. So the trip count was unknown when gcc reversed the loop. A plain `j < 0x154` folds to `li 339` and `bgez`. A static inline helper with an `n` argument folds the same way. So does `(p + 0x154) - p`.

lever: name the end pointer and use it only in the bound: `e = p + 0x154` and then `for (j = 0; j < e - p; j++)`. The cse2 pass folds `e - p` to the constant only after the loop pass. So the loop keeps the unknown-trip form (blez guard and bnez down-counter).

## Instance
W50 slus 8001DB78 (c3): the loop form matched with this lever. The target still failed at 5/29 on an outer-loop register swap, so it is ledgered. No banked rider proves it yet.
