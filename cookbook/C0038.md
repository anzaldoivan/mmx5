# C0038 — CRLF PsyQ headers break old-gcc cccp: use host cpp -undef
tags: toolchain,gcc,psyq · date: 2026-10-05 · phase/task: 1.6/T2 · origin: T2 gotcha

PsyQ 4.0 headers with CRLF line endings break the old-gcc psx cccp (`parse error before ->`, stray backslash). Preprocess with the host `cpp -undef` (as sozud/mmx4 does), then feed cc1. Origin: phase-1.6 T2.
