# C0109 — MMX5 stage poke must hit first gameplay load
tags: mmx5,redux,stage,poke · date: 2026-10-12 · phase/task: 2.2/T4 · origin: phase-ends/current/tasks/T4.md:23

In MMX5, a REDUX_STAGE poke (stage byte at 800136D4 hit) must hit the first gameplay stage load. That load is hit 4 on a pad-only boot. Earlier hits are menu flow. With an earlier hit, the stage object loop never runs, so stage objects never spawn. See tools/loadmap/prove.py `ovl3839` (REDUX_POKE_HIT=4).
