# Permuter target.o from linked bytes that keeps our relocations
A target.o made only of linked `.word`s has no relocations. The stock decomp-permuter scorer forgives a symbol field only when the target line has a relocation. So a relocating function's own C scores above 0 (fixture: 15).

Fix (tools/permuter/permute.py, 3.6 T2): compile the draft, read its `.rel.text` sites with symbol names.

At each site write `(linked & ~field) | (ours & field)`, where field is 0x03FFFFFF for R_MIPS_26 and 0xFFFF otherwise. Emit `.reloc <off>, <type>, <sym>` after the `.word`s. gas keeps the written field as the REL addend.

A section name works as the symbol once that section is declared (`.section .rodata`).

Limit: the target takes the draft's reloc symbol and addend, the same blind spot as `waves.py try` masking. The gate decides.

Trap: the permuter never prunes the other functions in a draft. A multi-function draft scores above 0 even when its function matches. Use single-function drafts for controls.
