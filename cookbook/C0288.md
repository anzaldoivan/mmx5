# C0288 — Several jump tables with one case set: one static inline switch helper, called per probe
tags: codegen,switch,jtbl,jump-table,inline,helper,static-inline,duplicate,rodata · date: 2026-11-01 · phase/task: 3.4/T13 · origin: W78 slus 8002F8FC

symptom: the target owns several jump tables with the same case set. Each table is followed by the same 0/1 value join (`j` with `li 1`, or `move 0`). Ours has one switch and one table, or a compare chain.

cause: each inline copy of a function body is expanded in full. A switch in a `static inline` helper gives one jump table for each call site.

lever: write the case test once as a `static inline s32` helper. It has the switch, `return 1;` in the cases and `return 0;` after it. Call the helper at each probe: `if (func_<vram>_hit(f(...))) { ... return; }`.
