# C0045 — Scratch build sample has a fixed floor: overlap it
tags: health,build,perf · date: 2026-10-05 · phase/task: 1.6/T8 · origin: T8 gotcha

A scratch-worktree build sample has a fixed split+build floor. The sample size does not shrink that floor. Run the sample in the background and overlap it with other health rungs. Origin: phase-1.6 T8 (carve rung).
