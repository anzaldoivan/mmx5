# C0287 — Loop constant hoisted into a saved reg: an s16 local for the difference keeps it in the loop
tags: codegen,loop,invariant,hoist,insn_count,s16,local,sll,sra,saved-reg · date: 2026-11-01 · phase/task: 3.4/T12 · origin: W77 F302C_ovl05

symptom: a constant is hoisted out of a loop into a saved register. The target keeps it in the loop, and the extra saved register changes the frame and the prologue.

cause: loop.c moves an invariant only when the loop is large enough (the `insn_count` threshold, loop.c:1837). An `s16` local adds `sll`/`sra` insns to the loop body. Then the loop is above the threshold, and the constant is not moved.

lever: compute the window difference into an `s16` local, then test it: `dx = tbl[n] - *(u16*)(g + 0xA); if ((u16)dx < 0x141)`. An `s32` local gives the hoist.

## Instance
W77 rockx5 func_800F302C_ovl05 (c2), a spawn loop with a window test. The `s16` local took the diff from 186 to 30 words at try 22. The rest was C0060 (array-ref field stores) and C0185.
Near: C0229 (an `s16` local for a sign-extended difference before a store), C0056 (an invariant load stays at the loop head).
