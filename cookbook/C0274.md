# C0274 — Table byte +2 folds into %hi(D+2), no hoist: read the word and shift, (u8)(*(u32*)&D[k] >> 16)
tags: codegen,loop,hoist,address,word-read,shift,table,lbu,offset,fold · date: 2026-10-31 · phase/task: 3.4/T7 · origin: W72 F7738_ovl04

symptom: a loop bound re-reads byte +2 of a table entry. Ours folds the +2 into the symbol (`%hi(D+2)`) and does not hoist the address. The target keeps the address at the symbol and hoists it into an s-reg.

lever: read the bound as a word and shift it: `(u8)(*(u32*)&D[0][k] >> 16)`. Every byte form (`((u8*)&D[k])[2]`, `p[k*8+2]`) folds the offset into the symbol.

## Mechanism
The word read keeps the memory reference at sym+0. Then loop.c hoists the full address and cse2 copies it into an s-reg. Combine later narrows the word read back to `lbu 2(reg)`. A pointer local in the condition hoists only the `lui`.
