# C0232 — Param stored to a u8 global before its andi: declare it s32, test (u8)param
tags: codegen,param,u8,s32,narrowing,andi,sb,store-order · date: 2026-10-24 · phase/task: 3.3/T25 · origin: W47 slus 8001B2E0

symptom: the target stores a parameter to a u8 global (`sb`) before it masks the value (`andi 0xFF`) for a test. A `u8` parameter narrows at entry, so ours has the `andi` first (diff 4 of 32 words).
