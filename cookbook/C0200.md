# C0200 — Harvest row idiom: a new idiom is the bare id, not new:C<id> (harvest.py check)
tags: workflow,harvest,check,cookbook-id · date: 2026-10-24 · phase/task: 3.3/T18 · origin: T18.c50 W40 harvest

symptom: `harvest.py check` counts a row as open when its idiom reads `new:C<id>`.

cause: the check takes a new idiom as the bare cookbook id. Only covered levers carry a prefix (`covered:C<id>`).

lever: write a new idiom as `C0196`, a covered one as `covered:C0069`, and none as `none` with rider `n/a`.

## Instance
T17.c50 and T18.c50 harvest builders (`.run/w4x/c50/harvest.py`) write the bare id.
