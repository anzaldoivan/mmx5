# C0117 — A PSX exe's sector-rounded image tail can be the start of bss
tags: psx,exe,bss,t_size,padding,shift · date: 2026-10-12 · phase/task: 2.3/T5 · origin: generalizable

The sector-rounded tail of a PSX exe image can hold the start of a zero-init buffer that straddles t_size. Check for labels in the trailing zeros before treating them as free fill.
