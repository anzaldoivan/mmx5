# C0032 — A jal target can be a fall-through label; reject starts preceded by plain code
tags: boundaries,oracle,mips · date: 2026-10-05 · phase/task: 1.5/T2.1 · origin: -

A jal target can still be a mid-function label (a fall-through entry point). A bytes-only boundary oracle should reject a start whose two preceding words are plain code (no terminator, no padding). Origin: phase 1.5 T2.1, tools/census/boundaries.py.
