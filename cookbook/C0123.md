# Address-keyed allowlists and cross-variant make targets under layout shift
- An allowlist keyed by site address breaks under any layout shift. Key it by symbol+offset, translating through the unshifted ELF. (2.4/T8)
- A make target that consumes another variant's build outputs (e.g. the SHIFT=1 dir) must build them itself, or the milestone chain breaks after `make clean`. (2.4/T7)
