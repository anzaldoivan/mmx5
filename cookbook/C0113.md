# C0113 — Wrap splat undefined_syms_auto in PROVIDE so object labels win
tags: splat,ld,provide,undefined_syms,reloc · date: 2026-10-12 · phase/task: 2.3/T3 · origin: generalizable

splat's undefined_syms_auto assigns names that objects also define. A plain -T assignment overrides the in-section label and turns relocations SHN_ABS. Wrap each entry in PROVIDE(name = addr) so the object's label wins.
