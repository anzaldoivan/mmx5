# C0020 — PsyQ lib padding does not segment game text
tags: psyq,segmentation,tu,padding · date: 2026-10-03 · phase/task: 1.3/T6 · origin: -

PsyQ library objects show 8-byte text padding at object boundaries. Game code from the same toolchain may not show it. Thus you cannot use zero padding to segment game text into TUs. Use forced boundaries (jumptables, libobj matches) instead.
