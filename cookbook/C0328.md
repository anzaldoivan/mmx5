# C0328 — Self call as jal with a frame, target has j: s32 function with return f(...), bare early return
tags: codegen,tail-call,recursion,return,return-type,s32,void,jal,frame · date: 2026-11-07 · phase/task: 3.4/T27 · origin: W92 slus 800182D8

symptom: the target ends with `j` to the function itself and has no frame for that call. Our build emits `jal` and a frame.

cause: gcc turns a self call into a jump only when the call is in a `return` of a value. A `void` function with a plain call keeps the `jal`.

lever: if the target ends in a self `j`, declare the function `s32` and write `return f(...)` at the end. Write the early exits as a bare `return;`. A `return 0` adds an `li v0` at the exit.
