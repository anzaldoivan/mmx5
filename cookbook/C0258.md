# C0258 — Table call sets up the table address before the argument addresses: read each argument into a local first
tags: codegen,table-call,jalr,argument,lui,local,sched,order · date: 2026-10-25 · phase/task: 3.3/T35 · origin: W57 slus 80054BB8

symptom: a table call passes global addresses as arguments. Ours sets up the table address (`lui`/`addiu`) before the argument `lui` pairs. The target sets up the arguments first.

lever: read each argument address into a local before the call expression, in target order. Then call through the table with the locals. Here `u8* a1 = D_800D1C00` and `u8* a2 = D_8009A0A0` come first.
