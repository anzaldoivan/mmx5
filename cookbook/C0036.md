# C0036 — Py3.14 pools: use explicit fork context
tags: python,multiprocessing,perf · date: 2026-10-05 · phase/task: 1.6/T1 · origin: T1 gotcha

Python 3.14 multiprocessing defaults to the forkserver start method on Linux; pools over large in-memory tables then pickle/reload them per worker. Use `multiprocessing.get_context('fork')` explicitly. Origin: phase-1.6 T1 (tools/sig/sig.py band).
