# C0213 — s8 arg indexing a table: three statements (idx, base, p) put the lui between the shifts
tags: codegen,s8,sign-extend,combine,sra,sll,lui,index,base-pointer · date: 2026-10-24 · phase/task: 3.3/T22 · origin: W44 slus 8003DAF4

symptom: `p = &D[arg0*8]` with an s8 arg. The sign extension (sll24/sra24), the table lui/addiu and the sll3 interleave wrong in the last words. Target order: sll24, lui, addiu, sra21.

mechanism: combine merges sra24 and sll3 into one sra21 at the position of the sll3. So the base load must sit between the extension and the multiply, in its own pseudo.

lever: write three statements in this order. First `idx = arg0;` (an s32 local, the extension). Then `base = D;` (a pointer local). Then `p = base + idx * 8;`.

Rejected: `&D[arg0*8]` puts the shifts together. `p = D; p += ...` loads the base before the sll. The indexed giv `D[arg0*8+i]` moves the loop constants early.
