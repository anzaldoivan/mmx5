# C0317 — Bit-clear loops with invariants out of order: a static inline helper with a mask local
tags: codegen,inline,helper,static-inline,mask,local,loop,invariant,bit · date: 2026-11-06 · phase/task: 3.4/T23 · origin: W88 FA71C_ovl39

symptom: two loops clear one bit each in a word table. The target loads the loop invariants in a fixed order and computes the mask before the address. Ours loads the base first, and the `i++` and the mask registers move.

cause: an inlined function copies its argument to a new pseudo. A mask local in the helper then gives its own pseudo to the mask. These pseudos change the invariant order and the schedule of the loop body.

lever: write the bit clear as a `static inline void` helper with a mask local. Use `s32 m = 1 << (31 - n % 32); D[n / 32] &= ~m;`. Call the helper from each loop.
