# Commit before any carve dry run

`carve.make_wt` builds the scratch worktree by copying dirty-tree paths over HEAD. A tracked file deleted in the
working tree has no source to copy and crashes it. Commit (or restore) every pending change before
`propagate.py sweep --dry-run` or any carve/propagate dry run.
