# C0225 — Dead lb of an s8 global before a call: branch on it with two identical arms
tags: codegen,lb,dead-load,s8,global,tail-merge,cross-jump,identical-arms · date: 2026-10-24 · phase/task: 3.3/T24 · origin: W46 slus 80055920

symptom: the target has a signed-byte load of a global (`lb`) whose value is never used, before a call. Ours has no load. A marked `*(volatile s8*)&D` read gives `lbu`, not `lb` (diff 1 word).

cause: a branch on the global with two identical arms is tail-merged by gcc. The compare goes, but the load of the s8 global stays.

lever: declare the global `extern s8 D` and branch on it with identical arms: `if (D < 0) call(a, b, c); else call(a, b, c);`. No FAKE marking needed.

## Instance
W46 slus 80055920 (c29): try 1 with one call lacked the `lb`, the volatile read gave `lbu`. The identical-arm branch matched (try 2).
Related: C0194 (volatile reload), C0050 (cross-jump law).
