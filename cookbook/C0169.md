# C0169 — Two-case switch with the wrong block order: write an if/else-if chain
tags: codegen,switch,if-else,block-layout,bnez,case · date: 2026-10-20 · phase/task: 3.3/T7 · origin: W29 FD9C0

symptom: a two-case dispatch on a byte lays out its branches in another order. The target tests `bnez` first and falls into case 0.
lever: write the two cases as `if (x == 0) {...} else if (x == 1) {...}`, not as a `switch`.

## Residual
W29 FD9C0_ovl07: `switch (e->unk7) { case 0: ... break; case 1: ... break; }` gives diff 31 of 37. gcc 2.95 lowers a two-case switch to a compare chain with its own block order.

## Lever
`if (e->unk7 == 0) {...} else if (e->unk7 == 1) {...}` matches. The `e->unk3 = 1` store then reuses the state register (`a0 == 1`) in the delay slot.
Related: C0072 (case order inside a switch) and C0161 (shared cases fold to a range test). Try this one when a small switch's block order is wrong.
