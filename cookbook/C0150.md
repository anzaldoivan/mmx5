# C0150 — Per-site field stores cross-jump into one tail, and a re-read u8 field gives per-use andi
tags: codegen,cross-jump,tail-merge,jump2,v0,gcse,andi,u8,re-read · date: 2026-10-19 · phase/task: 3.2/T3 · origin: .run/p32t3/c28 (W23 harvest)

symptom: (a) a shared tail `sb $v0,<field>` after per-site `li $v0,N`. (b) a per-test `andi rX,$a1,0xFF` on a u8 field.
lever: per-site field stores, and a field re-read

## Residual
rockx5 func_800F01A0_ovl08 (198 insns). (a) A shared `state` variable put the tail store in `$a0`, not `$v0` (diff 25, then 12 without it).
(b) A local u8 for `facing` dropped the target's repeated `andi 0xFF` (diff 8, then 5 with re-reads).

## Mechanism
(a) Each site writes `arg0->state = N` and then jumps or falls through to the same stores. The jump2 pass cross-jumps the identical tails. The `li $v0,N` stays at each site.
A join variable is a pseudo, and the allocator gives it a reg other than `$v0`.

(b) The source re-reads a u8 field at every test. GCSE replaces the later `lbu`s with a copy of the first one in `$a1`. Each QImode use zero-extends it again (`andi rX,$a1,0xFF`).
A local `u8` var is zero-extended once, so there is no `andi`.

## Lever
(a) Write the field store at each site (`arg0->state = 7; goto set;`). Keep only the common stores in the shared tail. Use no `state` variable.
(b) Write `arg0->facing` at every use, with no local copy. Related: C0050 (tail merge count).
