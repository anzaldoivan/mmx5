# C0027 — One-function splat c cut: [start, c, func] then [end, asm, rest]
tags: splat,c,segmentation · date: 2026-10-04 · phase/task: 1.4/T5 · origin: phase-ends/current/tasks/T5.md

To cut one function to C in splat, use `[start, c, func]` followed by `[end, asm, <remainder>]`. The source path is src/<alias>/<name>.c. undef_by_name.py resolves the C's extern calls into other segments. Source: 1.4/T5 and docs/ops/toolchain.md:38.
