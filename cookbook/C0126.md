# mk/*.mk include order: `:=` reads a variable at parse time
- Sorted `include mk/*.mk`: a `:=` assignment that reads a variable defined in a later-sorted file sees it unset.
- Symptom (2.5 T2.c1): D_SH resolved without the shift path, `make disc SHIFT=1` wrote build/disc/ROCK_X5.BIN.
- Fix: make the reader recursive (`=`), or move the definition to an earlier-sorted file.
